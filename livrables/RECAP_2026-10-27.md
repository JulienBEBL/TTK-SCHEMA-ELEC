## 1. Règle de travail à respecter

- Le `.xrs` est **généré** par `outils/ttk_schema.py` (décision de Julien du 27/10). La source de vérité est le script, pas le `.xrs`.
- Une modification faite à la main dans WinRelais est **écrasée** à la régénération suivante. Deux façons de l'éviter :
  1. reporter la modification dans `ttk_schema.py`, puis régénérer (méthode à privilégier) ;
  2. ou décider de geler le script et finir à la main, le jour où le schéma passe en finition. Ce choix doit alors être noté dans `docs/DECISIONS.md`.
- Régénérer en local avec la vraie librairie WinRelais :
  ```
  cd outils
  set TTK_LIB=C:\Users\Public\Documents\Elec-CAO\sym_electrotech
  python ttk_schema.py ..\schema\generes\TTK_AAAA-MM-JJ_vN.xrs
  ```
  Sans `TTK_LIB`, le script utilise `outils/librairie/`. Ce sont des symboles **reconstruits** depuis le `.xrs` du 27/10 : ils sont fidèles à ce qui était posé, mais ce n'est pas la librairie d'origine.
  Exception : `RC Contact NO 63-64 / 73-74 / 83-84` ont été **créés** en copiant le contact 53-54 et en renommant ses broches. S'ils n'existent pas dans la vraie librairie, il faut les créer, ou garder `outils/librairie/` pour ces trois symboles.
- Le script affiche « N problème(s) de contrôle » et doit afficher **0**. Il contrôle la géométrie, les chevauchements et les équipotentielles voulues (listes `MEMES` / `DIFFERENTS`). Ensuite, lancer `python xrs_tool.py verifier <fichier>`.
- Aperçu d'un folio sans WinRelais : `python apercu_xrs.py <fichier> 42 f42.png` (matplotlib).
- La date du cartouche se règle avec la variable `TTK_DATE` (par défaut 27/10/2026).
